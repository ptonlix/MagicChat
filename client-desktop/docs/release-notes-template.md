## 即应 Desktop v0.1.6

本版本进一步完善桌面端聊天体验，新增选择消息和通知提示音控制，补齐会话免打扰、原生主题同步与 macOS 菜单栏适配，并提升本地配置和跨平台更新的可靠性。

## 新增功能

- 新增“新朋友”体验：通讯录导航会提示待处理的入站申请，friends 通讯录和聊天页可直接打开
  同一申请对话框，集中搜索、查看申请历史并处理待处理申请。
- 支持选择消息，可参与单选或多选，并实时查看各选项的结果变化。
- 新增会话免打扰，可从会话菜单快速开启或关闭；免打扰会话仍保留未读提示，但不再显示未读数字和新消息通知。
- 设置中新增“新消息提示音”开关，关闭后不再播放普通新消息提示音，同时保留系统通知、未读数和会话状态更新。

## 体验优化

- 应用主题现在会同步到桌面原生窗口，浅色、深色及跟随系统模式下的标题栏显示更加一致。
- 优化服务器配置页面的布局与主题适配，提升首次连接工作空间时的可读性和操作体验。
- 优化会话列表状态展示，置顶和免打扰状态更加清晰，并支持实时同步状态变更。
- 优化 macOS 菜单栏图标，使其能够根据系统菜单栏背景自动适配显示。
- 完善卡片和选择消息中的成员提及展示，名称变化后可及时刷新。

## 稳定性改进

- Desktop 已移除删除好友入口；联系人资料页保留与当前 Web 一致的“添加好友/等待对方接受”
  状态，接受、拒绝和取消仍在“新朋友”对话框中处理。Desktop/Web 的删除好友内部调用链和
  Server 删除好友接口保持不变，不影响其他客户端。
- friends 模式下私信与发送被 Server 拒绝时，会展示服务端好友授权提示并保留草稿，便于关系
  恢复后重试；不在本地伪造发送成功。
- 邮箱验证码注册继续复用既有 Server 认证路径，本版本无需新增 Desktop API 或权限能力。
- 加强桌面设置的输入校验、旧版本配置迁移和失败恢复，避免异常配置影响应用启动。
- 配置写入采用串行和原子更新机制，降低并发修改、写入中断或磁盘异常造成配置不一致的风险。
- 设置保存失败时保留原有状态并显示安全、明确的提示，不暴露本地文件路径等信息。
- 优化 macOS 安装包与更新验证流程，增强版本、架构和制品完整性检查，并完善更新失败后的手动恢复路径。
- 整理客户端内部结构和跨平台发布流程，提升后续版本的构建与维护稳定性。
